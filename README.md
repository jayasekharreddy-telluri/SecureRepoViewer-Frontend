## Project Overview
PrivyCode frontend is an Angular application that works with the backend to allow developers to securely share **read-only access** to private GitHub repositories via temporary viewer links.  

The frontend provides:  
- Form validation for repository URLs  
- Display of temporary viewer links with view counts and expiry  
- In-app repository viewer (file tree + markdown rendering)  
- Notifications using Toastr  
- Real-time UI updates and error handling  

---

## Features
- **Form Validation:** Ensure only valid private GitHub URLs are accepted  
- **Temporary Link Display:** Shows link, expiry, and views left  
- **File Tree Viewer:** Browse repo structure without downloading  
- **Markdown Rendering:** Render `.md` files in-app  
- **Notifications:** Toastr notifications for actions like link creation, errors
